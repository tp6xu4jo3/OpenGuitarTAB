OpenGuitarTAB 隱私權政策

最後更新：2026 年 9 月 27 日

OpenGuitarTAB 是用來建立、管理及瀏覽吉他 TAB 曲譜的網站。本政策說明網站如何處理 Google 使用者資料。

存取的資料

經資料夾擁有者授權後，OpenGuitarTAB 會透過 Google Drive API 存取指定資料夾中的曲譜 JSON 檔案及必要的檔案資訊，例如檔名、檔案 ID、修改時間與上層資料夾。網站不會任意讀取指定資料夾以外的 Drive 檔案。

資料用途

上述資料只用於顯示曲譜、儲存修改、建立或刪除曲譜，以及提供公共曲庫與個人曲譜櫃功能。Google OAuth 憑證只在伺服器端用於取得 Drive API 存取權，不會提供給瀏覽器。

資料儲存與分享

曲譜檔案保留在資料夾擁有者的 Google Drive。網站使用 Vercel 提供網站與伺服器功能；服務供應商可能依其政策處理必要的技術紀錄。OpenGuitarTAB 不販售 Google 使用者資料，也不將資料用於廣告。

資料保留與刪除

曲譜會保留至使用者透過網站或 Google Drive 刪除為止。使用者也可以在 Google 帳戶的安全性設定中撤銷 OpenGuitarTAB 的存取權。

安全措施

網站使用 HTTPS，並將 OAuth 憑證保存在伺服器端環境變數中。任何網路服務皆無法保證絕對安全，但我們會限制資料使用於上述必要功能。

聯絡方式

若有隱私相關問題，請透過 OpenGuitarTAB GitHub Issues 聯絡。

OpenGuitarTAB 對 Google API 所取得資訊的使用及傳輸，將遵守 Google API Services User Data Policy，包括 Limited Use 規定。
